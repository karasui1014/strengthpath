# tools

## bundle.py — 1ファイル版の書き出し

```bash
cd ~/StrengthPath && python3 tools/bundle.py
```

`dist/strengthpath.html`（約267KB）が出ます。CSS・JS・画像7枚をすべて埋め込んだ単体ファイルで、
サーバーを立てずに開けます。スマホに送る／共有URLを出す／メールに添付する、といった用途向けです。

**本番（GitHub Pagesなど）には使いません。** 本番は `index.html` + `assets/` をそのまま置いてください。
1ファイル版はキャッシュが効かず、更新のたびに267KBを丸ごと再ダウンロードすることになります。

### 単体版で変わるところ

| | 通常版 | 1ファイル版 |
|---|---|---|
| Service Worker | 公開環境で有効（オフライン対応） | 使わない |
| 画像 | 別ファイル（キャッシュが効く） | base64で埋め込み |
| データの書き出し | JSONファイルをダウンロード | クリップボードにコピー |

ダウンロードは共有ビューアのサンドボックスで無効化されるため、コピー方式にしてあります。

### 注意

`<meta charset="UTF-8">` は必須です。これが無いと日本語が全部文字化けします（一度やらかしました）。
