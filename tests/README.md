# テスト

```bash
cd ~/StrengthPath && node tests/run.js
```

Node だけで動きます。ブラウザもビルドも不要です。
`assets/*.js` を最小のDOMスタブ上で読み込み、ロジックと文言を直接検査します。

## 何を見ているか

| 分類 | 主な内容 |
|---|---|
| 1. 適性チェック | 気持ち×余力の2軸判定。**「やる気はあるが時間がない人」が弾かれないこと**、3分岐すべてに到達できること |
| 2. 持ち味チェック | 34問・4段階、スコアが0〜100、**8つの道すべてに到達できること** |
| 3. 副業カタログ | 20件の必須項目、重みキーの実在、並び順、**20件すべてが上位3に入りうること**、代表4パターンの妥当性 |
| 4. 9つのやること | 全8タイプでちょうど9つ、id重複なし、nextStepの挙動 |
| 5. きろく | **休んでも減らない累計**であること、日付がローカル時刻基準（UTCずれなし） |
| 6. そうだん | 5種のプロンプト生成、副業候補の埋め込み、「否定しない」指示の存在 |
| 7. データ整合性 | 持ち味12・進みグセ5・道8の必須フィールド、テーマの色コード、投資の注記 |
| 8. 言葉づかいの憲法 | **否定ワード・世界観の比喩が混入していないこと**、文字化け、Gallup免責、リベ大の出典、「今日はここまで」の逃げ道 |
| 9. 保存と再開 | 途中離脱した状態を保持できること、JSONの往復 |

## 文言を編集したら必ず走らせること

8番のテストが「言葉づかいの憲法」を機械的に守らせています。
`動けない` `向いていない` `欠点` `弱み` などを書くと落ちます。
`探偵` `燈月` `ローファイ` といった世界観ワードも落ちます。
