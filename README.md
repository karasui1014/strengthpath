# 伴走スタジオ

「知ってるのに動けない」を終わりにするための、強み診断 × 行動伴走ツール。
副業をやりたいのにノウハウコレクターになって動けない人が、**自分で動けるようになる**ことがゴールです。

登録不要・完全無料・静的PWA。データはすべて利用者の端末内（localStorage）にのみ保存され、サーバーには一切送信されません。

## 設計思想

ノウハウコレクターが動けないのは、情報が足りないからではありません。
**「自分に合った動き方」が決まっていない**ことと、**行動を止めているブレーキが特定されていない**ことが原因です。

そこでこのツールは、以下の3点だけに絞っています。

| やること | やらないこと |
|---|---|
| 強みに合った動き方を1つに決める | 新しいノウハウを教える |
| 行動を止めているブレーキを特定する | 弱点の克服を求める |
| 15分サイズの一歩に分解して伴走する | 一度に複数の宿題を出す |

## 機能

- **34問の診断**（3〜4分）
  - 12資質 → 上位5つを「効くところ／空回りするとき／活かし方」つきで提示
  - 5つの行動ブレーキ → 上位2つを「なぜ起きるか／外し方／今日15分の処方箋」つきで提示
  - 8つの副業タイプ → 向いている型・最初の1円の取り方・つまずくポイント
- **90日ロードマップ自動生成** — タイプ別に3フェーズ13タスク。上から1つずつ潰す形式
- **日次チェックイン＋連続実行日数** — 「できなかった」も記録できる設計
- **AIコーチ プロンプト生成** — 診断結果・進捗・記録を全部埋め込んだプロンプトを生成。Claude / ChatGPT にコピペするだけ
  - 初回セッション / 週次ふりかえり / 手が止まった時 / 初収益の設計 / 面談準備（コーチ用）
- **コーチモード** — 複数のクライアントを切り替えて管理。セッション記録つき
- **バックアップ書き出し・読み込み**（JSON）

## 分類の中身

**12資質**（4カテゴリ × 3）

| 推進力 | 思考力 | 関係力 | 創造力 |
|---|---|---|---|
| 即断 / 完遂 / 挑戦 | 分析 / 構想 / 探究 | 共感 / 発信 / 支援 | 着想 / 表現 / 審美 |

**5つのブレーキ**
完璧主義 / 選択肢過多 / 自信不足 / 目的あいまい / ひとりぼっち

**8つの副業タイプ**
コンテンツ発信型 / 教える・講座型 / コーチ・伴走型 / 診断・コンサル型 / 制作・クリエイター型 / 代行・オペレーション型 / 企画・仕掛け型 / キュレーション・まとめ型

## ファイル構成

```
伴走スタジオ/
├── index.html          # 画面の器
├── manifest.json       # PWA設定
├── sw.js               # Service Worker（★更新時は CACHE のバージョンを必ず上げる）
└── assets/
    ├── data.js         # 12資質・5ブレーキ・8タイプ・設問・ロードマップ・プロンプト定義
    ├── app.js          # 採点／画面描画／イベント
    ├── style.css       # スタイル（ライト・ダーク自動対応）
    └── icon-*.png      # アイコン
```

**内容を変えたいときはほぼ `assets/data.js` だけ触ればOK**です。
設問の追加・資質の文言変更・ロードマップのタスク差し替えは、すべてこのファイルで完結します。

## ローカルで動かす

```bash
cd ~/伴走スタジオ && python3 -m http.server 8123
```

http://localhost:8123 を開く。

## 更新時の注意

`sw.js` の `CACHE` のバージョン番号を必ず上げること。
上げ忘れると古いキャッシュが残り、編集内容が反映されません。

## 法的な注意

本ツールの12資質・5ブレーキ・8つの型は、**副業における行動特性に特化した完全オリジナルの分類**です。
ストレングスファインダー®／CliftonStrengths®（Gallup社の登録商標）とは無関係であり、
同社の34資質名・診断結果・解説文は一切使用していません。
