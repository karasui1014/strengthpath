# StrengthPath

自分の持ち味から、**合う副業**と**次にやること1つ**を見つけるPWA。
副業をはじめたい人が、自分で動けるようになるためのツールです。

登録不要・無料・完全ローカル保存。データは端末の外に出ません。

---

## 言葉づかいの憲法

このツールでいちばん大事なのは機能ではなく **言葉** です。ここを崩したら別物になります。

1. **相手を否定しない。** 「動けない」「できていない」「原因」「弱み」は書かない。
2. **まず肯定してから、軽く提案する。** 「そういうタイプですね」→「だから、こうするとラクです」の順。
3. **頑張らせない。** どの画面からでも「今日はここまででOK」に逃げられる。
4. **一度に出すのは1つだけ。**

対象は「やりたい気持ちはあるけれど、腰が重い人」です。
正論・煽り・現状否定は、この人たちの手を止めるだけなので使いません。

### 具体的にどう言い換えているか

| ふつうのツール | StrengthPath |
|---|---|
| 「知ってるのに動けない」 | 「集めるのが好きなあなたへ。もう、材料はそろっています」 |
| 動けない原因 / ブレーキ | **進みグセ**（例：完璧主義 → 「こだわり型 ＝ いいものを出したい人」） |
| 診断・結果 | もちあじ |
| 弱みの克服 | 持ち味のまま、ラクに進む方法 |
| 連続◯日（休むと0に戻る） | **これまで◯回**（減らない。休んでも損しない） |

## めんどくさがりのための設計

- 設問は **4択・1画面1問**。「どちらとも」を置かず、迷う時間を減らす
- **途中でやめても、続きから再開できる**（回答は1問ごとに保存）
- ホームに出るのは **今日やること1つだけ**。9つの一覧は畳んである
- 「やった！」は **ワンタップ**。記録も気分入力も要らない
- 気が乗らない日は **3分でできる代わりのこと** が出る（そこから逃げてもOKと明記）
- 「今日はここまでで大丈夫。ここは逃げませんから。」が常に用意されている

## 流れ

```
① 適性チェック（3問）
      ├─ いま、はじめどき      → ② へ
      ├─ 気持ちは十分・時間だけ → 時間のつくり方3案 → ② へ
      └─ いまは別のほうが効く   → 固定費・つみたて・本業で上げる
                                （それでも②に進めます）
② どっち寄り6問 ＋ 進みグセ1問
      → 持ち味TOP5 / 進みグセ / 向いてる道
      → ここで結果は完成。合計10問で終わり
③ 合う副業（20コから相性順）
④ 9つのやること → 1つずつ実行 → きろく

（任意）もっと正確にしたい人だけ、あとから8問追加できる
```

**こたえる前でも行き止まりを作りません。** 結果が出るまでタブは「ホーム」「しごと」の2つだけ出します
（押しても何も無いタブを並べない）。しごとは<b>何もこたえずに20コすべて読めます</b>。
もちあじ・きろく・そうだんに直接来た場合も、そこに何が出るかを伝えて次の手を2つ示します。

**どの分岐でも行き止まりにしません。** 「いまは別のほうが効く」と出た人にも、副業に進むボタンは必ず残してあります。判断するのは本人です。

## 機能

- **適性チェック 3問** — 気持ち（変えたい）と余力（時間 / 手放せる）の2軸で見る
- **どっち寄り 6問** — 1問で2つの持ち味を同時に測るので、12種を6問で測れる
  - 「まず試してみる／まず調べてみる」のように、どちらを選んでも否定にならない対で聞く
  - **選択肢そのものを完結した文にしている**（「まず試してみる」「どちらかといえば、試すほう」…）
    A/Bのラベルを覚えて選び直す手間が要らず、読んで押すだけで済む
  - 上を選べば下は反対の値になる。つまり1タップが2種ぶんの答えになる
- **進みグセ 1問** — 5つから近いものを1つ選ぶだけ。使うのは最上位1つなので1問で足りる
- **合計10問で結果が完成する。** 追加8問は任意で、あとからいつでも足せる
  - 採点は「答えた問題の平均」なので、10問でも18問でも同じものさしで比べられる
  - 追加で道が変わっても、進めたやることと完了状態は引き継がれる
- **先に、正直なところを** — 実際の調査データ（月収の中央値3万円、理想との差、やめる理由）を見せたうえで、必ず「だからこうする」を3つ添える
- **副業カタログ 20コ**（19＋番外編）— 持ち味との相性順に並び、上位3つに「相性◎」
  - **最初の一歩は5手順**。何を用意して、どう動くかまで書いてある
  - 各項目に「いるもの / AIの使いどころ / 正直なところ / 効く持ち味」
  - **お金のこと**として「いくらになる / 最初の1円まで / 月5万円にするなら / はじめる費用 / 売る場所」
    - 単価・期間・必要な件数・初期費用・実在のサービス名を、20コすべてに具体的に書いている
    - 金額は目安であり収入を保証しない旨を明記。「稼げます」「確実に」等の断定はテストで禁止している
- **副業以外の道** — 固定費の見直し / つみたて投資という選択肢 / 本業で単価を上げる
- **9つのやること**（3章 × 3つ）をタイプ別に自動生成
- **報告してカードを送る** — できたことを6種類から選んで記録し、送れるカードにする
  - 「続けている」「しんどい」も選べる。数字が出ない時期こそ報告できるようにするため
  - カードは文字なので、LINEでもXでもどこにでも貼れる。応援は送った先でもらう
  - サーバーを持たない作りなので、誰に配っても同じように動く
- **きろく** — 動いた記録が累計で積み上がる
- **そうだん** — 結果・副業候補・進み具合を全部埋め込んだプロンプトを生成。ChatGPT / Claude にコピペ
- **ホーム画面に追加できる**（PWA）
  - iPhoneは自動で案内が出ないので、共有ボタンからの3手順を画面に出す
  - Androidなどは `beforeinstallprompt` を受け取って、ボタン1つで追加できる
  - すでに追加済みの人と、一度「いまはいい」を押した人には二度と出さない
- **テーマ6色 × ライト・ダーク・自動**
- **コーチモード** — 複数人を切り替えて伴走
- **バックアップの書き出し・読み込み**（JSON）

## ガイドキャラクター

画面に出てくるガイド役です。**設定や名前は一切出しません**（説明が増えると読む負担になるため）。
表情だけが場面に応じて切り替わります。

| ファイル | 表情 | 使いどころ |
|---|---|---|
| `normal.png` | ふつう | 最初の画面・あいさつ |
| `think.png` | 考えてる | 質問の途中・まだ始めていないとき |
| `surprised.png` | おどろき | 9つぜんぶ終わったとき |
| `idea.png` | 指を立てて提案 | 「気が乗らない日は、こっち」のシート |
| `happy.png` | 笑顔 | 結果発表・今日もう動いたとき |
| `wink.png` | ウインク | 1つ終えたときのトースト |
| `cat.png` | 猫 | ロゴマーク |

すべて背景透過の256px PNG（合計140KB）。差し替えるときは**同名・同サイズのPNGを置くだけ**です。
切り出し前の元素材は `.source/` にあります。

## ファイル構成

```
StrengthPath/
├── index.html
├── manifest.json
├── sw.js               # ★更新時は CACHE のバージョンを必ず上げる
└── assets/
    ├── data.js         # 持ち味・進みグセ・道・設問・一手・セリフ ← 文言はほぼここだけ
    ├── akari.js        # キャラ画像の呼び出し
    ├── app.js          # 採点・画面・イベント
    ├── style.css       # テーマ変数（--acc / --acc2 をJSが差し替える）
    ├── akari/          # ガイドの6表情＋猫（背景透過PNG）
    └── icon-*.png
```

文言の調整は **`assets/data.js` だけ** で完結します。

## ローカルで動かす

```bash
cd ~/StrengthPath && python3 -m http.server 8123
```

`localhost` ではService Workerを登録しません（古いキャッシュが配信される事故を防ぐため）。
公開環境でのみSWが動きます。**公開時は `sw.js` の `CACHE` のバージョンを上げること。**

## スマホで使う

| 対応したこと | 中身 |
|---|---|
| ホーム画面に追加 | `display: standalone`。追加するとブラウザのUIが消え、アプリのように開きます |
| iPhone対応 | `apple-mobile-web-app-capable` ほか。追加時の名前は「StrengthPath」 |
| アイコン | `any` と `maskable` の両方を用意（Androidで角が欠けないように） |
| ノッチ・ホームバー | `viewport-fit=cover` ＋ `env(safe-area-inset-*)` |
| 指で押せる大きさ | `@media (pointer: coarse)` で、押せるものは高さ44px以上を確保 |
| オフライン | Service Workerが本体・画像・アイコンをキャッシュ。一度開けば圏外でも動きます |
| 縦向き固定 | `orientation: portrait` |

## セキュリティ

知っている人にだけURLを渡す前提での対策です。

### やっていること

| 対策 | 内容 |
|---|---|
| 外部通信ゼロ | `fetch` / `XMLHttpRequest` / WebSocket / ビーコンを一切使っていません。入力内容が端末の外に出ることはありません |
| 保存はローカルのみ | すべて `localStorage`。サーバーもデータベースもありません |
| XSS対策 | 画面に出る値はすべて `esc()` を通しています。`eval` / `document.write` / `insertAdjacentHTML` は不使用 |
| 読み込むJSONの検証 | 知っているキーだけを拾い、型・範囲・長さを揃えてから使います。壊れたファイルでは落ちずに拒否します |
| 入力長の上限 | 名前60字・理由500字・メモ2000字など。記録は500件まで |
| CSP | `default-src 'none'` を基本に、画像は自分自身と `data:` のみ許可。通信先は無し |
| 検索避け | `noindex, nofollow, noarchive` |
| リファラ抑止 | `no-referrer`。外部リンクを踏んでも、どこから来たか相手に伝わりません |
| 外部リンク | `noopener` 付き。開くのはユーザーが押したときだけ（Claude / ChatGPT / YouTube検索の3つ） |

### やっていないこと（できないこと）

**パスワードによる保護はしていません。** 静的なページなので、画面にパスワード欄を付けても
ソースを見れば誰でも突破できます。気休めにしかならないため、あえて入れていません。

**URLを知っている人は誰でも開けます。** 実質の鍵はURLそのものです。
不特定多数に広まると困る場合は、URLの扱いに気をつけてください。

**保存データは端末ごとに独立しています。** 渡した相手のデータがこちらに見えることはなく、
逆にこちらから相手の進捗を確認することもできません。
