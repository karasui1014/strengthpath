# 一歩ノート

自分の持ち味から、次にやることを1つだけ決めるノート。
副業をはじめたい人が、**自分で動けるようになる**ためのPWAです。

登録不要・無料・完全ローカル保存。データは端末の外に出ません。

---

## 言葉づかいの憲法

このツールでいちばん大事なのは機能ではなく **言葉** です。ここを崩したら別物になります。

1. **相手を否定しない。** 「動けない」「できていない」「原因」「弱み」は書かない。
2. **まず肯定してから、軽く提案する。** 「そういうタイプですね」→「だから、こうするとラクです」の順。
3. **頑張らせない。** どの画面からでも「今日はここまででOK」に逃げられる。
4. **一度に出すのは1つだけ。**

対象は「やりたい気持ちはあるけれど、腰が重い人」です。
正論・煽り・現状否定は、この人たちの手を止めるだけなので使いません。

### 具体的にどう言い換えているか

| ふつうのツール | 一歩ノート |
|---|---|
| 「知ってるのに動けない」 | 「集めるのが好きなあなたへ。もう、材料はそろっています」 |
| 動けない原因 / ブレーキ | **進みグセ**（例：完璧主義 → 「こだわり型 ＝ いいものを出したい人」） |
| 診断・結果 | もちあじ |
| 弱みの克服 | 持ち味のまま、ラクに進む方法 |
| 連続◯日（休むと0に戻る） | **これまで◯回**（減らない。休んでも損しない） |

## めんどくさがりのための設計

- 設問は **4択・1画面1問**。「どちらとも」を置かず、迷う時間を減らす
- **途中でやめても、続きから再開できる**（回答は1問ごとに保存）
- ホームに出るのは **今日やること1つだけ**。9つの一覧は畳んである
- 「やった！」は **ワンタップ**。記録も気分入力も要らない
- 気が乗らない日は **3分でできる代わりのこと** が出る（そこから逃げてもOKと明記）
- 「今日はここまでで大丈夫。ここは逃げませんから。」が常に用意されている

## 機能

- **34問**（3分）→ 12の持ち味 TOP5 / 進みグセ / 向いてる道（8種）
- **9つのやること**（3章 × 3つ）をタイプ別に自動生成
- **きろく** — 動いた記録が累計で積み上がる
- **そうだん** — 結果と進み具合を全部埋め込んだプロンプトを生成。ChatGPT / Claude にコピペ
  - まず何から？ / 今週どうだった？ / 気が乗らない… / お金の話 / 面談の準備（コーチ用）
- **テーマ6色 × ライト・ダーク・自動**
- **コーチモード** — 複数人を切り替えて伴走。面談メモつき
- **バックアップの書き出し・読み込み**（JSON）

### 12の持ち味

| すすむ力 | かんがえる力 | つながる力 | つくる力 |
|---|---|---|---|
| みきり / やりきり / わくわく | みぬき / えがき / しらべ | きづき / つたえ / ささえ | ひらめき / かたち / こだわり |

### 5つの進みグセ
こだわり型 / 目移り型 / ていねい型 / のんびり型 / マイペース型（すべて肯定形）

### 8つの道
伝える / おしえる / よりそう / みぬく / つくる / まかせられる / しかける / まとめる

## ガイドキャラクター

画面に出てくるガイド役です。**設定や名前は一切出しません**（説明が増えると読む負担になるため）。
表情だけが場面に応じて切り替わります。

| ファイル | 表情 | 使いどころ |
|---|---|---|
| `normal.png` | ふつう | 最初の画面・あいさつ |
| `think.png` | 考えてる | 質問の途中・まだ始めていないとき |
| `surprised.png` | おどろき | 9つぜんぶ終わったとき |
| `idea.png` | 指を立てて提案 | 「気が乗らない日は、こっち」のシート |
| `happy.png` | 笑顔 | 結果発表・今日もう動いたとき |
| `wink.png` | ウインク | 1つ終えたときのトースト |
| `cat.png` | 猫 | ロゴマーク |

すべて背景透過の256px PNG（合計140KB）。差し替えるときは**同名・同サイズのPNGを置くだけ**です。
切り出し前の元素材は `.source/` にあります。

## ファイル構成

```
一歩ノート/
├── index.html
├── manifest.json
├── sw.js               # ★更新時は CACHE のバージョンを必ず上げる
└── assets/
    ├── data.js         # 持ち味・進みグセ・道・設問・一手・セリフ ← 文言はほぼここだけ
    ├── akari.js        # キャラ画像の呼び出し
    ├── app.js          # 採点・画面・イベント
    ├── style.css       # テーマ変数（--acc / --acc2 をJSが差し替える）
    ├── akari/          # ガイドの6表情＋猫（背景透過PNG）
    └── icon-*.png
```

文言の調整は **`assets/data.js` だけ** で完結します。

## ローカルで動かす

```bash
cd ~/一歩ノート && python3 -m http.server 8123
```

`localhost` ではService Workerを登録しません（古いキャッシュが配信される事故を防ぐため）。
公開環境でのみSWが動きます。**公開時は `sw.js` の `CACHE` のバージョンを上げること。**
