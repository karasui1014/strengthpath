# 元素材（切り出し前）

`assets/akari/*.png` はここから切り出しています。表情の切り出し位置を変えたくなったらこれを使ってください。

- `bust_area.png` — バストアップ表情集（2行3列）。normal / think / surprised / idea / happy / wink の元
- `cat_area.png` — 相棒のシャム猫の元
- `char_sheet.png` / `cs_a.png` / `cs_b.png` — キャラクターシートの他パーツ

切り出しは背景（RGB 239,231,223）からの距離でアルファを作る方式。
いちばん背景に近い衣服はセーターで距離36なので、しきい値16〜30なら服を消さずに背景だけ抜けます。
